# EWV — Android Video Editor

نسخه آغازین پروژه مستقل EWV برای اندروید.

## ساختار فعلی
- نوار ابزار افقی بالای صفحه اصلی با پیمایش افقی؛ این نوار جزء ثابت طراحی است و نباید حذف شود.
- فضای پیش‌نمایش پلیر
- کنترل‌های پخش، توقف، واگرد و ازنو (فعلاً نمایشی/آماده توسعه)
- ناحیه خط زمانی با ردیف ویدیو و جایگاه ترک‌های صوتی/متن
- دسترسی پایین صفحه به رسانه، لایه‌ها، پروژه و تنظیمات
- انتخاب فایل رسانه از حافظه دستگاه

## ساخت APK
نیازمندی‌ها: JDK 17، Android SDK، Gradle 8.9.
```bash
gradle assembleDebug
```
خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## GitHub Actions و مشکل اجرا نشدن Build
Workflow در `.github/workflows/android.yml` تنظیم شده است:
- با Push روی همه Branchها اجرا می‌شود (`branches: ["**"]`).
- اجرای دستی از طریق `workflow_dispatch` نیز فعال است.

## راهنمای رفع مشکل Push/Commit طبق متن راهنمای پروژه
اگر در MGit، Commit/Push با مشکل ناهماهنگی تاریخچه یا رد شدن به‌روزرسانی Remote روبه‌رو شد:
1. ابتدا از پوشه پروژه یک نسخه پشتیبان تهیه کنید.
2. در MGit از منوی Pull گزینه **Force Pull** را اجرا کنید؛ این روش در متن راهنمای ارائه‌شده به‌عنوان راهکار تجربه‌شده ذکر شده است.
3. پس از بررسی وضعیت فایل‌ها و تاریخچه، Commit و سپس Push را دوباره انجام دهید.

توجه: Force Pull ممکن است وضعیت محلی را با Remote جایگزین کند؛ پیش از اجرا، از تغییرات محلی مهم نسخه پشتیبان بگیرید.
